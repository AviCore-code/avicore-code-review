# Product Hunt Launch — AviCore Code Review

## Tagline
AI-powered code review with severity labels and risk scoring

## Description
AviCore Code Review is a lightweight, dependency-free code review tool that analyzes git diffs and outputs structured review comments with severity labels and risk scoring.

## Key Features
- 40+ static analysis rules (security, quality, performance, best practices)
- Severity labels: Critical, Required, Nit, Optional, FYI
- Risk scoring: 0-10 with MINIMAL/LOW/MEDIUM/HIGH levels
- Multiple output formats: Console, JSON, Markdown
- GitHub Action for CI/CD integration
- Zero dependencies — pure Node.js stdlib
