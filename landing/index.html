Features

40+ Rules

Comprehensive static analysis covering security, correctness, error handling, performance, readability, architecture, async patterns, and testing.

Risk Scoring

0-10 risk score with MINIMAL/LOW/MEDIUM/HIGH levels. Know at a glance if your code is safe to merge.

Multiple Formats

Console, JSON, and Markdown output. Integrate with CI/CD pipelines, GitHub Actions, or use standalone.

Zero Dependencies

Pure Node.js stdlib. No npm install required. Works anywhere Node.js runs.

Git Diff Native

Works with any git repository. Review PRs, branches, or pipe diffs from stdin.

Programmatic API

Import as a module and integrate into your own tools, editors, or CI systems.

Severity Levels

Critical

Security vulnerabilities, data loss risks. Must fix before merge.

Required

Correctness issues, error handling gaps. Should fix before merge.

Nit

Style, minor improvements. Fix if convenient.

Optional

Suggestions, alternatives. Consider for future.

FYI

Informational, awareness. No action needed.
